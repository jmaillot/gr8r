**Flow C: out-of-band deletion → next restore clears flag.** Fetch misses → mirrorMissing → clearMirrorFlag (column=0 + `mirror_flag_cleared:<dest>` audit) → refusal `restoreArchiveMissing` with server detail → client refreshes both histories → badge re-resolves honestly. **COMPLETE** (verified at all three restore seams).

**Flow D: rotation prune.** Rotation pass → delete set → pruneRunMirrors per destination → `remote_pruned = 1` + audits; sole-copy guarded; live runs untouched. **COMPLETE.**
