new keys land in en.json and fr.json in one place and the batch plans translate a stable catalogue.

estimate formatter, French values for every new key.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| template-created task titles → stored document data | the title stored at creation is locale-rendered text — it becomes document data and is later rendered with esc(); stored titles must never carry markup (the catalogue's plain-text contract holds: t() never escapes, call sites escape) |
| legacy notification rows → renderer | legacy rows with stored text render verbatim through esc() — the legacy text is document data, never trusted markup |
