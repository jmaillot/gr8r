<objective>
The RFC 8058 one-click unsubscribe endpoint end-to-end: `POST /unsubscribe/:token` verifies the Phase 41 HMAC token, merge-upserts the stored prefs row with `email_digest=false`, and answers with a self-contained HTML page whose verified/neutral variants differ only by localized body text. Ships contract-first (D-13): the security-contract comment block and the test suite pinning it land with the route.

Purpose: This is the milestone's first anonymous mutating route — SC-1..SC-4 of Phase 42 live here. Phase 41 shipped the frozen token contract; this plan makes a real mail-client POST actually turn the digest off.

Output: Route in server.js top-level chain, pure helpers in mailer.js, test/unsubscribe-route.test.mjs, notif.unsubscribe.* i18n keys (EN+FR) with catalogue pin bump, DEPLOY.md note.
</objective>

| T-42-02 | Information Disclosure | response matrix | high | mitigate | No existence oracle: every token outcome → 200 with the same one-template page, identical status/headers, only the localized message differs; pinned by envelope-parity and hostile-token tests (D-03/D-04) |
