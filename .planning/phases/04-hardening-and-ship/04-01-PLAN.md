| test process → spawned server | Test code chooses env, port and DATA_DIR for a real server process. |
| test → filesystem | Temporary databases and backups are written outside the repository. |
| CI → npm registry | Only existing dependencies are installed in this plan; no new package is added. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering | `test/helpers/server.mjs` spawn | low | mitigate | Spawn with an argument array and no shell; every env value is a test constant or an explicit override. |
| T-04-02 | Information Disclosure | Test DATA_DIR selection | medium | mitigate | The harness always supplies its own `mkdtemp` directory unless a migration test passes one explicitly; no test reads the repository `data/` or port 8080. |
| T-04-03 | Denial of Service | Parallel server boot in CI | low | accept | `--test-concurrency=2` bounds simultaneous servers; each uses an ephemeral port and its own database. |
| T-04-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package-legitimacy gate: this plan installs nothing new. Any future install must be checked on npmjs.com and pinned in the lockfile. |
