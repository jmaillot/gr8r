<objective>
Close the two confirmed verification gaps in Phase 35's honest-undo surface (VERIFICATION.md Gaps 1 and 2).

Gap 1 (WR-01): the undo `onAction` in `src/actions/teams.js` fires union `setMemberTeams` PUTs even when the awaited `pushNow()` doc push failed — guaranteed `400 unknownTeam` per PUT against a server doc without the restored team, plus a divergent-state corner when the server doc still carries the team id. Fix: early-return with the existing `err.changeTeam` toast when `pushed.ok === false`, before any authority PUT.

Gap 2 (WR-02): `pushNow()` in `src/core/store.js` never takes the `pushing` mutex during its own PUT, so a `save()` scheduled during that window can overlap it → two concurrent PUTs of the same doc → false-positive `409` → `S.ui.conflict = true` full-app conflict lock mid-undo. Fix: `pushNow()` takes `pushing = true` (released in a `finally`) around its PUT.

Purpose: without these two fixes SC1 ("undo restores the purged memberships") is not honestly delivered on the failure path. DEPLOY-01 is already fully delivered and verified by 35-02 — no work here touches it.
Output: two small production fixes + two new source-scan pins in `test/undo-membership.test.mjs` (7 tests total, all passing).
</objective>
