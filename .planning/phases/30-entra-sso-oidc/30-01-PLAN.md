<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Entra IdP → callback | The authorization response (`code`, `state`) and later the id_token cross from the external IdP into server.js — all attacker-influenceable until verified |
| Browser → /api/auth/oidc/start | Anonymous unauthenticated requests hit the start route; state/PKCE bootstrap must not be predictable or reusable |
| Env vars → OIDC factory | Configuration is trusted but must fail closed on partial/absent values |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-30-01 | Spoofing | /api/auth/oidc/callback state check | high | mitigate | Fresh `crypto.randomBytes` state per start, hashed storage, `timingSafeEqual` compare, delete-on-use consume |
| T-30-02 | Spoofing | authorization code interception | high | mitigate | PKCE S256 verifier sent only on the server-side token POST; stolen code useless without the verifier |
| T-30-03 | Spoofing | id_token injection | high | mitigate | `nonce` claim validated timing-safe against the per-flow nonce before any identity resolution |
| T-30-04 | DoS | discovery/JWKS/token fetches | medium | mitigate | `AbortSignal.timeout(10_000)` on every outbound fetch; fail closed to generic error redirect (Pitfall 7) |
| T-30-05 | Information disclosure | unconfigured OIDC routes + partial config | medium | mitigate | 404-no-oracle on both routes; identical generic `notFound` body regardless of which var is missing (D-02) |
| T-30-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new packages by design (D-01 + milestone invariant pinned by test/dependencies.test.mjs) — no install tasks exist in this phase; `oidc.js` imports node built-ins only |
</threat_model>
