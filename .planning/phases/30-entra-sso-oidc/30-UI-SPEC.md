## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary SSO CTA | **"Continue with Microsoft"** — reuse existing key `page.auth.continueMicrosoft` (EN) / "Continuer avec Microsoft" (FR). Zero new string. |
| Divider | reuse `page.auth.or` — "or" / "ou". Zero new string. |
| SSO error (generic, no-oracle) | **NEW key** `page.auth.ssoError`: EN `"Sign-in with Microsoft failed. Please try again."` FR `"La connexion avec Microsoft a échoué. Veuillez réessayer."` — one generic string for ALL failure causes (state mismatch, provider error, denied, timeout). Deliberately does not name the cause (no-oracle), does not reference the password path (must read correctly in SSO-only mode), and offers the next step (retry). |
| Empty state | none — no new empty states exist (D-05 reuses existing onboarding) |
| Destructive actions | none in this phase |

i18n gate: the one new key lands in **both** `src/locales/en.json` and `src/locales/fr.json` (i18n-scan gate, RESEARCH Pitfall 8). If a distinct error is needed for "configured but account inactive", use the same string — no second variant.
