The locked decisions this plan implements: D-01 (mechanical, behaviour-preserving), D-02 (the lint
is not weakened), D-05 (the plural shape, `{n}`), D-07 (`t()` never escapes; the call site
escapes the interpolated values), D-08 (`data-*` and action keys are never translated), D-09 (the
dotted, namespaced taxonomy), D-10 (JSON catalogue, 174-name icon baseline).

## The extraction protocol — the same rules in every sweep wave

1. **Find.** Run `node scripts/i18n-scan.mjs --report` and take the findings for the files of
   this wave. Every finding is a literal the interface shows to a user.
2. **Name.** Give the literal a key under the namespace this wave owns. The key is dotted, every
   segment starts with a lowercase letter, and it extends the phase-5 taxonomy — it never
   replaces a seed key and never goes under the reserved `contract.` namespace.
3. **Copy the TEXT, not the markup.** The catalogue carries the text the user reads. A literal
   written `Create account &amp; join` in the source becomes `Create account & join` in the
   catalogue, because the catalogue holds text and the HTML parser decodes the bare `&` the same
   way. The rendered text does not change.
4. **Interpolate.** A literal that sits inside a larger interpolated string becomes a catalogue
   value with a placeholder — `{name}`, `{email}`, `{title}`, `{count}` — and the interpolated
   value is passed at the call site. The count placeholder is `{n}` (D-05). The placeholder name
   is a single word, because the interpolation regex is `/\{(\w+)\}/g`.
5. **Escape at the sink.** `t()` never escapes (D-07). A value interpolated into markup is
   escaped by the sink that already escapes: `toast()` escapes its own message, `empty()` escapes
   its title and its text. Where the sink does NOT escape — a template literal's text node, an
   `aria-label`, a `data-tip` — the call site escapes the interpolated value with the existing
   `esc()`. Never both, or the value is escaped twice.
6. **Do not touch the machine identifiers.** The `data-a`, `data-r`, `data-v`, `data-k`, `id`,
   `class`, `style` and `href` values, the action keys, the route ids, the status ids, the label
   ids, the icon names and the stored preference values stay exactly as they are (D-08).
7. **Prove.** After the file is swept, the scan reports nothing for it, the allow-list loses the
   corresponding entries, and the suite is green.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a catalogue value → a toast | the value is spliced into a message that a sink escapes |
| a catalogue value → a modal body | the value is spliced into markup the sink does not always escape |
| a document value → an interpolated catalogue value | the interpolated value comes from the document, i.e. from user data |
| `src/` → the icon bundle | every quoted token in a `.js` file under `src/` can pull a Lucide icon into the bundle |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-22 | Tampering | a catalogue value → a toast or a modal | high | mitigate | A catalogue value may carry no `<`, no `>` and no `"`; the phase-5 lint rejects it, the toast escapes its own message and the modal's own escaping is preserved — an interpolated value is escaped at the point of interpolation (D-07, D-10) |
| T-06-23 | Tampering | `data-a` / `data-r` / `data-v` | high | mitigate | The action keys, the routes and the values are machine identifiers and are never translated; the wave's verification counts the `data-a` sites to prove they survived (D-08) |
| T-06-24 | Tampering | the icon bundle | medium | mitigate | The catalogue stays JSON, every key is dotted, and the 174-name baseline is asserted by `test/build-locales.test.mjs`; a literal removed from `src/` that was the last reference to an icon name would turn that test red (D-10) |
| T-06-25 | Repudiation | the allow-list | medium | mitigate | A stale allow-list entry is a violation, so the list cannot be padded with dead entries; the scan is the proof that the wave's literals are really gone |
| T-06-SC | Tampering | package installs | high | accept | This phase installs no package and adds no `dependencies` block |
</threat_model>
