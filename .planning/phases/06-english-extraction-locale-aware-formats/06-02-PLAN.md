<objective>
Replace the hand-rolled English date, time and number machinery with `Intl`-backed, per-locale
cached formatters, without changing one English character.

Purpose: this is the riskiest surface of the phase. The hand-rolled `MON`/`MONL`/`WD`/`WDL`
arrays and the `fmtDate()`, `relDate()`, `ago()`, `dayBucket()` and `fsize()` functions are the
places where a locale change would show up first, and they are the places where a mechanical
refactor is most likely to change a meaning by accident. The CONTEXT names the English output as
the regression oracle: `Jul 24`, `Today`, `just now`, `5m ago`, `2d ago`, `1 KB` — those strings
ARE the specification, and this plan measures the new formatters against them character by
character. It also builds the French side the roadmap's success criterion 3 names: `24/07/2026`, a
24-hour clock and « il y a 2 jours ».

Output: the `Intl` primitives and the formatter surface in `src/core/i18n.js`, the delegating date
API in `src/core/utils.js`, the locale-driven `fsize()` in `src/ui/helpers.js`, the three
`dayBucket()` call sites, the catalogue labels the formatters read, and `test/i18n-format.test.mjs`.
</objective>

    **The caches.** Three module-level `Map`s, one per primitive, keyed by the locale and the

    ```js
    const dateTimeCache = new Map();
    const numberCache = new Map();
    const relativeCache = new Map();
    ```

    already follows.

    **The per-locale format table.** One table describes how each locale renders, because the
    English output is frozen by the behaviour-preservation contract and the French output is
    frozen by the roadmap's success criterion:

    ```js
    const LOCALE_FORMATS = {
      en: {
        date: {
          base: { month: 'short', day: 'numeric' },
          withYear: { month: 'short', day: 'numeric', year: 'numeric' },
        },
        relativeStyle: 'narrow',
        bytes: ['B', 'KB', 'MB'],
      },
      fr: {
        date: {
          base: { day: '2-digit', month: '2-digit', year: 'numeric' },
          withYear: { day: '2-digit', month: '2-digit', year: 'numeric' },
        },
        relativeStyle: 'long',
        bytes: ['o', 'ko', 'Mo'],
      },
    };
    ```

    with a documented fallback for a locale the table does not carry: the `dateStyle: 'short'`
    options for both date forms, the `long` relative style and the English byte units.

    Three entries in that table are load-bearing and each one is a measured decision, not a taste:

    - `date.base` for `en` is `{month:'short', day:'numeric'}` and NOT `dateStyle:'short'`, because
      `dateStyle:'short'` renders `7/24/26` in English and the English interface must keep
      rendering `Jul 24`.
    - `relativeStyle` is `narrow` for `en` and `long` for every other locale: the English
      interface's compact durations (`5m ago`) are part of its current appearance, and the
      roadmap's French output is the long form (`il y a 2 jours`).
    - `bytes` is `['B','KB','MB']` for `en` because the English interface renders `1 KB`, while
      `Intl`'s own unit style renders `1 kB` and `512 byte` — the unit style is therefore NOT
      used for file sizes; the number and the unit are formatted separately.

    **The exported formatters.**

    - `formatDate(value, options = {})` — `value` is a `Date`, an ISO string or a timestamp.
      `options.pattern` is one of `'d/M'`, `'M/d'`, `'yyyy-MM-dd'`, `'MMM d'` or `'auto'`.
      **The pattern `'MMM d'` and the pattern `'auto'` mean the same thing** — the locale's date
      form — because D-04's resolution is that the stored `'MMM d'` IS the sentinel: the document
      cannot distinguish "never touched" from "explicitly picked the default", and the default
      is `'MMM d'`.
      An explicit pattern is composed by hand exactly as today (`d/M` → `24/7`, and `24/7/2026`
      when `options.long` is true), in every locale, because an explicit user choice always wins.
      The locale form uses the locale's `date.base` options, and switches to `date.withYear`
      when `options.long` is true OR the date's year differs from the current year's. For
      `fr` the two option sets are the same, so the year is always present — `24/07/2026`.
      `options.year` overrides that rule: `'auto'` (the default) is the rule above, `'always'`
      forces the `withYear` options and `'never'` forces the base options with their `year` key
      removed. The `'never'` mode exists for the settings preview, which must show the locale's
      date SHAPE and stay the same in every year — plan 06-03 uses it.
    - `isAutoDateFmt(value)` — `value === 'auto' || value === 'MMM d'`. The sentinel test, next
      to the formatter that honours it. It is a pure read: it never writes the preference bag,
      never calls `save()` and never touches the shared document.
    - `formatRelativeDay(value)` — `today` → `t('common.today')`, `+1 day` →
      `t('common.tomorrow')`, `-1 day` → `t('common.yesterday')`, between 2 and 6 days → the
      locale's short weekday name, otherwise `formatDate(value)`.
    - `formatRelativeTime(timestamp)` — under a minute → `t('common.justNow')`; under an hour →
      the relative time in minutes; under a day → in hours; under a week → in days; otherwise
      the date. The relative time uses `Intl.RelativeTimeFormat` with
      `{ style: LOCALE_FORMATS[code].relativeStyle, numeric: 'always' }` — **never**
      `numeric: 'auto'`, which turns minus two days into `avant-hier`.
    - `dayBucketId(timestamp)` — `today` / `yesterday` / `week` / `earlier`, with today's
      thresholds (`0`, `-1`, `> -7`, otherwise).
    - `bucketLabel(id)` — `t('bucket.' + id)`.
    - `formatNumber(value, options = {})` — the locale's `Intl.NumberFormat`, cached.
    - `formatFileSize(bytes)` — below 1024 → the number and `bytes[0]`; below 1048576 → the
      number of kilobytes rounded to an integer and `bytes[1]`; otherwise the number of megabytes
      with exactly one fraction digit and `bytes[2]`. The number is the locale's number format,
      so French groups with U+202F.
    - `formatTime(value, options = {})` — `options.cycle` is `'12'`, `'24'` or `'auto'`. `'auto'`
      uses the locale's `timeStyle: 'short'`, which is a 12-hour clock in English and a 24-hour
      clock in French; `'12'` and `'24'` pass `hour12` explicitly.
    - `monthName(date, style)` and `weekdayName(date, style)` — the locale's month and weekday
      names, `style` being `'short'`, `'long'` or `'narrow'`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a preference value → an `Intl` constructor | `prefs.dateFmt` and `prefs.tz` come from the shared workspace document |
| a timestamp → a formatter | the timestamp comes from the document, i.e. from user data |
| a catalogue value → a formatter result | the labels the formatters return are spliced into markup by the call sites |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04 | Tampering | `prefs.tz` → `Intl.DateTimeFormat` | high | mitigate | `prefs.tz` stores `'(GMT-07:00) Pacific Time'`, which `Intl` rejects with a `RangeError`; no formatter in this plan receives it, the browser's resolved zone is used, and the IANA migration stays deferred (D-04) |
| T-06-05 | Denial of service | `prefs.dateFmt` → the date pattern | medium | mitigate | Only the four known values are honoured: `'MMM d'` is mapped to the `'auto'` sentinel and `'d/M'`, `'M/d'`, `'yyyy-MM-dd'` are composed by hand; an unknown value falls back to `'auto'`, so a corrupt document cannot reach an `Intl` constructor with an arbitrary option set |
| T-06-06 | Information disclosure | the relative-time and the file-size formatters | low | accept | The formatters receive a timestamp or a byte count and return a formatted number; no personal datum, credential or document content passes through them |
| T-06-07 | Tampering | `src/locales/en.json` (the new labels) | medium | mitigate | The new values are plain words with no `<`, `>` or `"`; the phase-5 catalogue lint rejects a value that carries one, and the values are read through `t()`, which never escapes (D-07, D-10) |
| T-06-SC | Tampering | package installs | high | accept | This phase installs no package and adds no `dependencies` block; the formatters are the platform's own `Intl` and the zero-runtime-dependency guard asserts it |
</threat_model>
