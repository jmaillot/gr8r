## The extraction protocol

The seven rules of plan 06-07's protocol apply unchanged: find with the scanner, name the key
under the namespace this wave owns, copy the TEXT and not the markup, interpolate with a
single-word placeholder and `{n}` for a count, escape at the sink and never twice, never touch a
machine identifier, and prove it with the scan, the allow-list and the suite.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a catalogue value → the chrome | the value is spliced into the sidebar, the topbar or the document title |
| a stored id → a catalogue key | the id comes from the document and is used to build a key |
| a catalogue value → an overlay | the value is spliced into a drawer, a modal, a popover or the palette |
| `src/` → the icon bundle | every quoted token in a `.js` file under `src/` can pull a Lucide icon into the bundle |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-26 | Tampering | a stored id → a catalogue key | medium | mitigate | The key is built from an id that comes from the document, so a tampered document could name a key that does not exist; `t()` returns the key itself in that case, never an empty string, and a test asserts that every route id and every vocabulary id has a key |
| T-06-27 | Tampering | a catalogue value → the chrome and the overlays | high | mitigate | The values carry no `<`, no `>` and no `"` (the phase-5 lint), and the interpolated values are escaped at the point of interpolation with the existing `esc()` (D-07) |
| T-06-28 | Tampering | the stored vocabulary | high | mitigate | The ids, the routes, the action keys and the icon names are never translated: the vocabulary changes its DISPLAY only, and the document still holds the same English ids, so an existing document keeps working untouched (D-08, I18N-07's groundwork) |
| T-06-29 | Tampering | the icon bundle | medium | mitigate | The catalogue stays JSON and every key is dotted; the 174-name baseline is asserted by `test/build-locales.test.mjs` and a removed literal that was an icon's last reference turns that test red (D-10) |
| T-06-SC | Tampering | package installs | high | accept | This phase installs no package and adds no `dependencies` block |
</threat_model>
