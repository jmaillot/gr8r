# Plan 78-02: Client — Gate-Aware Surfaces, Await-Access Page, Operator Console

**As a** user without workspace-creation rights,
**I want** an honest await-access page (no creation surface) that enters the app automatically once I gain access,
**so that** I am never stranded in a creation flow the server will refuse.

## Artifacts this phase produces

- Gate-aware `canCreateWorkspace` getter + boolean `state.creation` (src/core/api.js)
- Hidden create button for gated users (src/overlays/popovers.js)
- Await-access view: extension of the existing `no-workspace` auth view with a 15 s visible-tab-only poll (src/pages/auth.js, src/main.js, src/actions/actions.js)
- Operator console promote/demote UI (src/pages/settings.js + actions) wired to the 78-01 endpoints
- New e2e spec `e2e/await-access.spec.mjs`
- 5-locale keys for await page + operator console actions
