## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-80-04 | Information Disclosure | save route ordering | high | mitigate | sameOrigin → requireUser → isInstanceAdmin BEFORE any target lookup — non-operators get an undifferentiated 403, no workspace-ID oracle; integration test pins the indistinguishability |
| T-80-05 | Tampering | request body → group_mappings | high | mitigate | Allow-list validation (canonicalized GUID shape, DB workspace existence, 3-token role) before any INSERT; nothing invalid ever stored; unique (guid, workspace) index as backstop |
| T-80-06 | Elevation of Privilege | role field | high | mitigate | roleTokenRefusal + table CHECK both enforce owner/admin/member only; a 'viewer' mapping refuses at save (locked decision, Pitfall 5) |
| T-80-07 | Tampering | label field | low | accept | Stored as opaque display-only text, never a match key, not rendered until Phase 83 (escaping happens there); acceptance rationale: no sink exists in this phase |
| T-80-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new dependencies this phase — no installs occur; `test/dependencies.test.mjs` pins the dep set and Dockerfile COPY list, keeping T-80-SC structurally satisfied with no checkpoint needed |
