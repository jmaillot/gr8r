- **View/revoke sessions** (SESS-01/02/03): settings mount → GET → render (device icon, IP, this-device badge, per-row revoke, disabled revoke-all at ≤1 row) → DELETE → refresh. Opaque 12-char id prefixes, never token hash; per-row delete user_id-scoped.
- **Password change** (PASS-01/02/03): PATCH → verify current pw + rehash + revoke-others in ONE `transaction()` → honest toast + banner, guarded by test/password-copy-honesty.test.mjs. Reuses the exact SESS-02 keep-current primitive.
- **2FA enrollment** (TFA-01–04): enroll → QR (`renderQrSvg`) + copyable secret → verify-before-enable → one-time recovery modal (transient state, never persisted).
- **Login second factor** (TFA-05): `pending2fa` parks client on '2fa' card → replay-guarded TOTP or burn-once recovery → session minted in same transaction that deletes the challenge. `tfaBackToSignIn` does a real server logout (D-61).
