### WARNINGs

1. **[Pre-existing, environmental] Full e2e suite: 140 passed / 1 failed (VIEW-02 saved-views).** Failure is `page.goto('/')` → "Cannot navigate to invalid URL" during `signIn` — the standalone `npx playwright test e2e/saved-views.spec.mjs` invocation (no `--config e2e/playwright.config.mjs`) runs without `use.baseURL`; and inside the configured full run the same spec passed when re-run in isolation against a fresh server. **Proof this audit:** `E2E_REUSE_SERVER=false npx playwright test --config e2e/playwright.config.mjs e2e/saved-views.spec.mjs:79` → **1 passed**. Unrelated to Phases 69/70/71 (saved-views subsystem, zero shared files). No action required for v2.6; recommend documenting the config-required invocation for the spec.
2. **[Pre-existing, environmental] 71-03 webhook double-fire failure** (documented in 71-03-SUMMARY): reminder window opens 08:00 UTC; suite runs before it emit 0 claim rows. Proven environmental by clock injection in 71-03; this audit's full `npm test` (run ~12:0x CET, post-window) shows **0 fail / 1737 pass** — consistent with the diagnosis. Self-healing; no fix shipped (standing constraint forbids gate edits).
3. **[Cosmetic UX] Subtask include is opt-in on the export modal.** `DEFAULT_OPTIONS.subtasks = false` (model.js:25) and the modal ships it as an unchecked checkbox (modals.js:411). Phases 70's child rows therefore only appear when the user ticks "Subtasks" — which matches the pre-existing R3 opt-in design (not a regression, and `test/make-export-samples.mjs` correctly sets `subtasks: true` for UAT samples). Flagged only so the milestone auditor can confirm this is the intended product behavior for "subtasks in Timeline/Board XLSX".
