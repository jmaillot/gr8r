## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| export model to chart caches and source cells | Counts travel twice — as cells and as cached series values — and must agree |
| redacted document to Board and Members rows | Assignee names and member rows must never widen beyond the exported task set |
| user text to chart categories | A task title can become a category label in a series cache |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-54-10 | Information Disclosure | Board, Members and Milestone rows | medium | mitigate | Every row derives from the model's exported top-level rows, which come from the redacted document; members are the assignee set of those rows, never the workspace roster; a test asserts no member outside the exported set appears |
| T-54-11 | Tampering | chart cache versus source cells | low | mitigate | Cache arrays are the same arrays written into the block cells in the same pass; the xlsx test compares sheet values with each chart's cache |
| T-54-12 | Denial of Service | Board and Members row volume | medium | mitigate | Row count is bounded by the exported tasks; no per-card shape, chart or merged range is created, so cost stays linear in rows |
| T-54-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan installs nothing; the writer was pinned behind the plan-02 blocking checkpoint |
</threat_model>
