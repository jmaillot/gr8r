## Milestone Summary

### Key Decisions
- **Instance-operator privilege model**: revocation scoped to a single instance operator via an additive `is_instance_admin` DB flag stamped at boot (ADMIN_EMAIL), NOT workspace-admin — avoids tenant-boundary privilege inflation (research Pitfall 6).
- **Single decrypt boundary**: `requireTotpSecret` is the only caller of `decryptTotpSecret`; fail-closed 503 touches only TOTP-verify/disable endpoints.
- **Recovery-code exclusivity enforced structurally**: `recovery_codes` lookups exist only in the login burn path; regen/disable use a strict 6-digit gate.
- **Audit-log location**: server-side `security_log` for instance-level actions (not the per-workspace activity log).
