<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> GET /api/auth/sessions | The caller's cookie identifies the user. Untrusted because a crafted cookie or a stolen token could enumerate sessions. |
| Client -> DELETE /api/auth/sessions/:id | The caller provides a session id. Untrusted because the caller could provide a foreign user's session id. |
| Client -> DELETE /api/auth/sessions/others | The caller's cookie identifies the user. Untrusted because a cross-origin request could revoke all sessions. |
| Session insert sites -> sessions table | The request headers (user-agent, IP) are written to the database. Untrusted because a client can send crafted user-agent strings. |
