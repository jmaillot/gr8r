<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Legacy DB -> openDb() | An existing database from before Phase 14 crosses into the new schema via ensureColumn. Untrusted because the legacy schema may lack any or all new columns. |
| Stored doc -> normalizeDoc() | A document stored in the database may contain legacy sessions/tfa fields. Untrusted because a stale client or a pre-migration document can carry them. |
| Client doc -> docFromClient() | A document submitted by a client may contain sessions/tfa fields. Untrusted because a stale client can resurrect them. |

Phase-level threats mitigated elsewhere: T-14-01 through T-14-04 and T-14-07 target the session endpoints (planned in 14-03) and are owned by 14-03's register.
