# Milestone v3.4: Requirements (archived 2026-11-24 — all complete) — UX Polish & Backup Console Refinement

**Defined:** 2026-11-23 — from owner fix list + ratified rulings (GFS naming, digest aggregation, cross-workspace pickers-only) + research SUMMARY.md (4 dimensions, HIGH confidence).

**Core Value:** Self-hosted, zero-dependency, multi-tenant project-management workspace — hardening before features. v3.4 refines existing operational surfaces; zero new dependencies.

## v3.4 Requirements

### Instance Roles (Governance)

- [x] **ROLE-01**: The Super Admins & Roles section is a role-tabbed view (Super Admin / Backup Operator / Restore Operator tabs) and is renamed "Instance Roles"
- [x] **ROLE-02**: A user holding multiple roles appears once per tab with stacked grant entries (role block, granted date, granted by) aligned to shared columns
- [x] **ROLE-03**: The user picker in the Instance Roles tab and in the Grant dialog is selectable like the Teams > Edit team picker, and the Grant dialog search works

### Backup Console (tasks + runs)

- [x] **BKUI-01**: The task list reads as a real table (no blocks-in-blocks) with humanized schedule ("Every Monday at 00:00"), populated Next run, and a Last run column with status (success/warning/error)
- [x] **BKUI-02**: Editing a scheduled task pre-fills its current values (cron included) with the "Edit backup task" header above the block
- [x] **BKUI-03**: Task retention editing offers all four GFS scales (day/week/month/year)
- [x] **BKUI-04**: A unified run history across all tasks renders with real columns and filters (task, trigger, status); viewers only see runs they are authorized to see (instance-scope via hasInstanceRole, workspace/project-scope via live membership)

### Backup Naming

- [x] **BKNAME-01**: Archive filenames AND run labels carry `<instance-name>-<scope>-<slug>-<gfs>-<date>` with workspace/project names resolved (never raw ids); manual runs carry no GFS marker
- [x] **BKNAME-02**: The GFS category is computed by one pure function shared with rotation, stored on the run row (additive column, dual-engine DDL) — archives are never renamed after creation

### Cross-workspace visibility

- [x] **XWS-01**: Super Admin, Backup Operator and Restore Operator see all workspaces in the Backup & Restore scope pickers only; `workspacesForUser` and app navigation are byte-unchanged

### Settings

- [x] **SET-01**: My Access shows the project icon (not the tick icon), or a column layout for a better overview
- [x] **SET-02**: API Keys offers a clear button removing revoked keys only (audit trail preserved)
- [x] **SET-03**: The Settings > General > Workspace URL displays on a single line
- [x] **SET-04**: The Invite Member > Edit Teams team picker is selectable like the Teams > Edit team picker

### Backup/Restore Core

- [x] **BKRST-05**: A project backup archive can be restored as NEW (import-as-new) or as OVERWRITE of an existing project (total replacement, snapshot-first, typed collision refusal, same guard chain, global restore lock unchanged) — added at phase-94 close from owner request ("je veux pouvour overwrite ou restore as new")

### Notifications

- [x] **NOTIF-01**: The daily digest sends one email per user per day across all workspaces (workspace-grouped sections inside); root cause of the 4× duplicate documented, with a pinned multi-workspace regression test

## Future Requirements (deferred)

- SMB/FTP backup destinations (v2 destination family)
- Backup format v2
- Backlog items not in the owner's v3.4 list

## Out of Scope (explicit exclusions)

- **No general cron DSL** — the 5-field cron subset and builder presets stay as-is (custom crons keep an honest raw-expression display)
- **No retention for manual archives** — shipped invariant (task_id NULL); only a hint is added
- **No silent auto-purge of revoked keys** — purge is an explicit user action
- **No operator visibility outside Backup/Restore pickers** — navigation, workspace switcher and project lists unchanged
- **No archive format change** — "gr8r backup v1" (D-86) stays frozen; naming is metadata/filename only
- **No re-run-from-history write paths**
