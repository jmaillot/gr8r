## The extraction protocol

The seven rules of plan 06-07's protocol apply unchanged: find with the scanner, name the key
under the namespace this wave owns, copy the TEXT and not the markup, interpolate with a
single-word placeholder and `{n}` for a count, escape at the sink and never twice, never touch a
machine identifier, and prove it with the scan, the allow-list and the suite.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a catalogue value → a toast | the value is spliced into a message that a sink escapes |
| a catalogue value → a modal body | the value is spliced into markup the sink does not always escape |
| a document value → an interpolated catalogue value | the interpolated value comes from the document, i.e. from user data |
| `src/` → the icon bundle | every quoted token in a `.js` file under `src/` can pull a Lucide icon into the bundle |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-41 | Tampering | a catalogue value → a toast or a modal | high | mitigate | A catalogue value may carry no `<`, no `>` and no `"`; the phase-5 lint rejects it, the toast escapes its own message and the modal's own escaping is preserved — an interpolated value is escaped at the point of interpolation (D-07, D-10) |
| T-06-42 | Tampering | `data-a` / `data-r` / `data-v` | high | mitigate | The action keys, the routes and the values are machine identifiers and are never translated; the wave's verification counts the `data-a` sites to prove they survived (D-08) |
| T-06-43 | Tampering | the icon bundle | medium | mitigate | The catalogue stays JSON, every key is dotted, and the 174-name baseline is asserted by `test/build-locales.test.mjs`; a literal removed from `src/` that was the last reference to an icon name would turn that test red (D-10) |
| T-06-44 | Repudiation | the allow-list | medium | mitigate | A stale allow-list entry is a violation, so the list cannot be padded with dead entries; the scan is the proof that the wave's literals are really gone |
| T-06-SC | Tampering | package installs | high | accept | This phase installs no package and adds no `dependencies` block |
</threat_model>
