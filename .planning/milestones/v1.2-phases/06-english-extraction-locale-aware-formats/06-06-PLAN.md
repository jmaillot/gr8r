<objective>
Convert the 16 measured English plural expressions into catalogue plural objects, so the count is
chosen by the locale's CLDR categories and never by the source.

Purpose: `n > 1 ? 's' : ''` is the English rule written into the code, and it is wrong in every
language that is not English: French says « 0 fichier » where the English rule says « 0 files »,
and a million takes its own category. The phase-5 layer already knows how to select a plural
member — the value is an object keyed by the CLDR category and the category comes from
`Intl.PluralRules` — so this plan only has to change the sixteen expressions into sixteen
catalogue lookups, with the count passed as `{ n }`. The English rendering must not change by a
single character, and the markup around the converted phrases must stay exactly where it is.

Output: the plural objects in `src/locales/en.json`, the sixteen call sites, and
`test/i18n-plural.test.mjs`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a count → a catalogue lookup | the count comes from the document, i.e. from user data |
| a catalogue value → the DOM | the value is spliced into a toast, a modal title or a modal body |
| the count → the plural selection | the count decides which CLDR member is selected |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-18 | Tampering | a plural value → the DOM | high | mitigate | The values are plain text with no `<`, `>` or `"`; the phase-5 catalogue lint rejects a value that carries one, and the values that reach markup are escaped by the sink (the toast's `esc(msg)`, the modal's own escaping) — D-07 and D-10 |
| T-06-19 | Tampering | the count → the plural selection | medium | mitigate | The category comes from `Intl.PluralRules` over the locale, never from a comparison in the source; the count is a number the code computed, and a count that is not finite resolves to the `one` member without throwing |
