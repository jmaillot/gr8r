## Warnings

1. **WARNING (REM-04, REM-01)** — Reminder email dedup vs. failure isolation: the `reminders_sent` claim commits with the doc write, and `queueNotifEmails` runs strictly **post-commit** (correct ordering). If SMTP is down at the claimed pass, the notification row exists but the email is never retried (dead-SMTP test asserts isolation, not retry). Accepted per 27-01 decisions ("window-open catch-up" re-emits only on later offsets/dates); noted as a known semantics, not a wiring break.
2. **WARNING (AUD-03)** — The audit trail card's e2e coverage is code-reading + full-suite green only; no dedicated Playwright spec exists for the trail UI (24-03 explicitly decided this). The server contract is pinned by tests; the render path is verified by trace only.
3. **WARNING (KEY-03, D-K9)** — A permanently-undecryptable envelope re-mints the D-74 backup on every rotation boot until manual intervention; bounded and asserted by WR-02, documented in DEPLOY.md. Operational sharp edge, not a wiring defect.
